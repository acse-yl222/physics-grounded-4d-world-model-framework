# 两地城市模块一致性与 SUMO 补齐结果

日期：2026-09-30。范围：South Kensington、White City；UAV / bird 保持原状。

已对齐建筑、风场、温度、日照、污染示踪、积水、SUMO 交通、日变化温度和 TfL 公共交通的工具接口与协议视图，并让规划/RSI 任务支持两个场景。保留各场景的真实地理、继承的坐标变换及原始分辨率；能力一致不表示科学精度相同。

## 实际执行与验证

- 两地建筑模型均完成共享体素化入口试跑；南肯辛顿另保留经过节点变换烘焙的仿真 GLB。
- 两地共 24 份选定运行清单通过协议验证，18 个模块视图及 2 个建筑+交通视图通过浏览器检查。
- 149 项 Python 测试、5 项查看器基础测试通过。
- 两地各运行基线、限速至 70%、同种子基线复跑；每次 300 秒、100 次合成出行。
- 同场景三次运行的出行路线和出发时刻相同；基线复跑的完整轨迹逐字节一致；限速产生不同轨迹。
- 6 次最终交通运行均无碰撞报告、无车辆瞬移。
- 两地各完成 99 帧日照驱动的三维温度诊断：32 m 水平 / 8 m 垂直网格、继承状态、固定风场。
- 两地规划任务的准备、预算工具、RSI 演化与最终评价流程均通过 fixture 测试；没有据此声称真实 LLM 或 RSI 效果提升。

## 尚未完成的科学校准

- SUMO 当前仍为合成需求与推测信号。尚未将 DfT 计数点方向匹配到道路并拟合 OD，不能称为已校准的真实交通数字孪生。White City 推测感应信号仍有无控制检测器的 SUMO 提示，需在正式信号校核中处理。
- 日变化温度采用受控常量环境、均匀表面参数和冻结风场，不是实测天气驱动；White City 已去除旧风场掩码中的人为封闭底层。
- 历史风、太阳、积水和污染数组只是保真接入，没有重跑整个多物理场研究；污染仍为无量纲示踪，地形与道路信号尚无完整实测校核。
- 交通排放与污染场未在这次工作中建立经校准的动态耦合，规划 agent 的综合跨模块优化仍需单独实验。
