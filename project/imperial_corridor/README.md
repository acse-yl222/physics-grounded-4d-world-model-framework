# Imperial corridor

An 8 km × 8 km domain centred between Imperial College's South Kensington and
White City campuses (origin lon -0.200473, lat 51.506427). It covers Kensington,
Chelsea, Notting Hill, Shepherd's Bush, Hammersmith, Paddington and Hyde Park.

`project.json`, `configs/` and `views/` are versioned. `input/overture/` and `runs/`
are local data and are not committed. Build with
`src/urban_geometry/image_to_threejs/build_run.py` and retain with `p4d retain`.
Overture data is ODbL (OpenStreetMap-derived) and must be attributed if published;
landmark reference sources are listed in each run's `data/landmarks.json`.
