# Wind–pollution integration: source-code handoff

This small archive is for sharing and reviewing the implementation directly.
It includes the coupling workflow, wind/VAE and pollution model implementations,
physical-reference generation code, and the local reproduction entry point.
It is NOT a standalone offline reproduction dataset.

## Where to start

- `code/workflow.py`: model loading, wind patch inference, conversion to pollution
  wind latents, pollution inference, the 5000–6000 recursive loop, and metrics.
- `code/vendor/yuhang/model.py` and `inference.py`: pollution architecture and
  checkpoint-controlled preprocessing/clipping.
- `code/vendor/scaled/scaled/`: wind U-Net and autoencoder implementations.
- `code/vendor/yuhang/data_generation/`: physical pollution and wind-latent preparation.
- `run_local.py`: the local prepare/check/run/plot entry point for the data bundle.
- `README_LOCAL.md`: instructions for running once the separate data bundle is obtained.
- `SOURCE_INFO.json`: source versions and checksums for this small code package.

## Running the experiment

The full reproduction bundle is shared separately because it contains large files.
Download it from the [shared Google Drive folder](https://drive.google.com/drive/folders/166itkp91W-gNv2L8Qw7hELTU0olf8PCL?usp=drive_link).
Download `wind_pollution_reproduction_bundle.zip` and `SHA256SUMS.txt`,
place both beside `run_local.py`, and follow `README_LOCAL.md`.
Use the data ZIP inside the folder, not a new outer ZIP generated by downloading
the entire Google Drive folder. If access is requested, contact the sender.
The runner verifies the bundle and uses its exact recorded code/weights/data.
It does not fetch private repositories or use the sender's authentication token.

The separate bundle supplies the wind model, VAE and pollution checkpoints;
geometry/source arrays; initial W_5000 and C_5000; and physical reference fields
for error evaluation. None of these large binary assets is included here.
Viewing source needs no GPU. Full inference needs suitable NVIDIA GPU memory.

## Scope and limitations

This is the full 1024-domain regression-wind → pollution integration experiment.
It predicts 20 increments of 50 from an initial state at 5000. Reference fields
are used only for evaluation. The current coupled result loses concentration
amplitude; sharing/reproducing the implementation does not establish accuracy.
Historical Yuhang geometry and VAE equivalence remain assumptions. Concentration
is not labelled as a validated PM2.5 mass unit, and time labels are update indices.

This source handoff includes the known caller tolerance adjustment from 1e-7
to 1e-6 in physical preparation. The separate completed-run bundle and its file
hashes remain the authoritative record for exact reproduction. No physical data
or reference output is regenerated just by opening this archive.
