# Published city presentation resources

Selected Delhi and Thapar geometry and recorded fields, published by explicit user authorization on 2026-10-12.
This data-only branch is separate from main and pages. The framework website uses immutable revision URLs.

resources.json records every file size, SHA-256, source manifest and licensing notes. Gzip chunks decode to the exact original GLB/NPY bytes; no simulation or geometry simplification is performed. Source manifest files are provenance records of the original complete local runs, not claims that compressed website transport is a protocol run encoding.

Preserve source attribution in project/<scene>/previews/<version>/provenance/project.json. No blanket licence is asserted. Original runs, source snapshots, private settings, credentials and recovery histories are not included.
